# ember-canon snapshot

`~/Projects/ember-canon` was a loose directory under version control by nothing
at all. It is archived here verbatim so the folder could be removed without
losing anything.

Measured against `ember` before archiving: 125 files, of which **35 exist
nowhere in ember** and 78 more differ in content. Some of the missing ones —
`docs/ds4-fidelity-audit.md`, `scripts/prove_kv_reuse.sh`,
`scripts/prove_streaming_and_disk.sh`, `scripts/prove_first_token.sh` — appear
in **zero** commits of ember's history, so this was the only copy.

Nothing here has been merged forward. It is a snapshot, not a branch to build on.
`build-stub/` was excluded as a build artifact.
